# Bank Management System

A desktop banking application built with Java Swing and MySQL.

## Features
- User sign-up (3-step registration) and login with card number and PIN
- Deposit and withdrawal
- Fast cash
- Balance enquiry
- Mini statement
- PIN change

## Technologies Used
- Java
- Swing (GUI)
- MySQL (database)
- JDBC
- IntelliJ IDEA

## How to Run
1. Install Java (JDK) and MySQL.
2. Create the database and tables used by the project.
3. Update the database username and password in `Conn.java`.
4. Add the MySQL JDBC connector (jar) to the project libraries.
5. Run `Login.java` to start the application.
